# Retired Rust experiment

BreakMock selected Go as its maintained implementation. This prototype is retained
for historical comparison only. It is not maintained, included in CI or shipped
in the BreakMock executable. New development belongs in the Go implementation
at the repository root.

The final experiment and its comparison history are preserved on
[`codex/rust-port`](https://github.com/Breaking-IT/BreakMock/tree/codex/rust-port).
See [the measured Go/Rust comparison](../GO_JOURNAL_OPTIMIZATION.md) for the results.
